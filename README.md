# QR Code Generator

A pure frontend QR code generator built with Vite, React, and `qrcode`.

## Features

- Browser-only QR generation.
- SVG export by default.
- PNG export option.
- Error correction levels: Low (7%), Medium (15%), High (25%), Best (30%).
- Live preview and local downloads.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
